# ✨ 기능 명세서

Komjirak Frame의 주요 기능과 세부 사양을 정의합니다.

## 1. 사진 선택 기능

### 1.1 사진 불러오기
- **설명**: 갤러리에서 1~10장의 사진을 선택
- **요구사항**:
  - 최소 1장, 최대 10장 선택 가능
  - 다중 선택 지원
  - 선택한 사진 미리보기
  - 선택 취소 및 재선택 가능

### 1.2 사진 순서 조정
- **설명**: 선택한 사진의 순서를 변경
- **요구사항**:
  - 드래그 앤 드롭으로 순서 변경
  - 번호 표시로 현재 순서 확인

## 2. 콜라주 프레임 생성

### 2.1 자동 레이아웃 추천
- **설명**: 선택한 사진 개수에 맞는 레이아웃 자동 제안
- **레이아웃 종류**:
  - 1장: 단일 프레임
  - 2장: 가로/세로 2분할, 대각선 등
  - 3장: 3분할, 2+1 조합 등
  - 4장: 2x2 그리드, 1+3 조합 등
  - 5장~10장: 다양한 그리드 및 조합 레이아웃

### 2.2 레이아웃 템플릿 선택
- **설명**: 미리 정의된 다양한 템플릿 제공
- **템플릿 카테고리**:
  - 그리드형 (균등 분할)
  - 매거진형 (크기 다양)
  - 스토리형 (세로 강조)
  - 파노라마형 (가로 강조)

### 2.3 사용자 정의 레이아웃
- **설명**: 사용자가 직접 레이아웃 커스터마이징
- **기능**:
  - 각 사진 영역 크기 조절
  - 사진 위치 이동
  - 여백 조정

## 3. 사진 편집 기능

### 3.1 크롭 (자르기)
- **설명**: 각 사진을 프레임에 맞게 자르기
- **기능**:
  - 자유 비율 크롭
  - 고정 비율 크롭 (1:1, 4:3, 16:9 등)
  - 회전 기능

### 3.2 필터 적용 (선택적)
- **설명**: 사진에 기본 필터 적용
- **필터 종류**:
  - 흑백
  - 세피아
  - 밝기 조절
  - 대비 조절

### 3.3 프레임 스타일
- **설명**: 사진 사이 경계선 및 배경 스타일 설정
- **옵션**:
  - 경계선 두께 조절
  - 경계선 색상 선택
  - 배경 색상 선택
  - 모서리 둥글기 조절

## 4. 미리보기 및 저장

### 4.1 실시간 미리보기
- **설명**: 편집 중 실시간으로 결과 확인
- **기능**:
  - 확대/축소
  - 전체 화면 미리보기

### 4.2 저장 기능
- **설명**: 완성된 콜라주를 저장
- **옵션**:
  - 고화질 저장 (PNG/JPG)
  - 해상도 선택 (1080p, 2K, 4K)
  - 갤러리에 자동 저장
  - 공유 기능 (SNS, 메신저 등)

## 5. UI/UX

### 5.1 직관적인 인터페이스
- 단계별 가이드 제공

### 5.2 반응형 디자인
- 다양한 화면 크기 지원
- 가로/세로 모드 지원

### 5.3 성능 최적화
- 이미지 로딩 최적화
- 메모리 관리

## 기술적 고려사항

### 필요한 Flutter 패키지 (예상)
- `image_picker`: 사진 선택
- `photo_view`: 이미지 확대/축소
- `flutter_image_compress`: 이미지 압축
- `image`: 이미지 처리
- `path_provider`: 파일 저장 경로
- `permission_handler`: 권한 관리
- `share_plus`: 공유 기능
- `cached_network_image`: 이미지 캐싱
- `flutter_staggered_grid_view`: 그리드 레이아웃

### 성능 목표
- 10장 사진 로딩: < 3초
- 레이아웃 전환: < 0.5초
- 고화질 저장: < 5초
- 메모리 사용: < 200MB
