# Magazine Layout Feature Specification

## 📖 개요
사용자가 매거진, 포토북, 에세이 스타일의 전문적인 레이아웃을 쉽게 만들 수 있는 기능입니다.

## 🎯 목표
- 일반 그리드 레이아웃을 넘어 매거진 스타일의 자유로운 구성 제공
- 다양한 크기와 비율의 사진을 조화롭게 배치
- 스토리텔링과 시각적 계층 구조를 강조하는 레이아웃

## ✨ 주요 기능

### 1. 매거진 스타일 프리셋 템플릿

#### 📸 3장 - Feature Story
- **용도**: 메인 스토리 강조
- **구성**: 큰 메인 이미지 (2/3) + 작은 보조 이미지 2개
- **스타일**: 잡지 표지, 여행 기사 레이아웃
- **셀 구조**:
  ```
  [  메인 이미지  ][ 보조1 ]
  [  (큰 사진)   ][ 보조2 ]
  ```

#### 📰 4장 - Spread
- **용도**: 양면 펼침 페이지 스타일
- **구성**: 균형잡힌 4개 이미지 (2개는 크게, 2개는 작게)
- **스타일**: 매거진 스프레드, 이야기 전개
- **셀 구조**:
  ```
  [ 작1 ][  큰1    ]
  [  큰2    ][ 작2 ]
  ```

#### 📝 5장 - Photo Essay
- **용도**: 포토 에세이, 심층 스토리
- **구성**: 히어로 이미지 + 3개 보조 이미지 + 하단 와이드
- **스타일**: 다큐멘터리, 여행 에세이
- **셀 구조**:
  ```
  [  히어로   ][ 1 ]
  [  이미지   ][ 2 ]
  [           ][ 3 ]
  [   하단 와이드   ]
  ```

#### 🎨 6장 - Modular Grid
- **용도**: 모듈식 디자인, 포트폴리오
- **구성**: 다양한 크기의 모듈을 조합
- **스타일**: 현대적 그리드 시스템
- **셀 구조**:
  ```
  [  큰1    ][ 1 ]
  [         ][ 2 ]
  [ 3 ][ 4 ][ 5 ]
  ```

#### 📚 7장 - Storytelling
- **용도**: 스토리 전개, 타임라인
- **구성**: 오프닝 이미지 + 중간 시퀀스 + 하단 마무리
- **스타일**: 스토리북, 여행 일지
- **셀 구조**:
  ```
  [  오프닝  ][ 1 ]
  [          ][ 2 ]
  [ 3 ][ 4 ][ 5 ]
  [   마무리 와이드   ]
  ```

#### 🎉 8장 - Event Mosaic
- **용도**: 이벤트, 파티, 행사 사진
- **구성**: 역동적인 모자이크 배치
- **스타일**: 이벤트 하이라이트, 페스티벌
- **셀 구조**:
  ```
  [   상단 와이드   ][ 1 ]
  [ 2 ][ 3 ][ 4 ]
  [ 5 ][ 6 ]
  [ 7 ][  하단    ]
  ```

#### 🖼️ 9장 - Mood Board
- **용도**: 무드보드, 컨셉 전달
- **구성**: 중앙 포커스 + 주변 이미지들
- **스타일**: 인테리어, 패션 무드보드
- **셀 구조**:
  ```
  [  중앙    ][ 1 ]
  [  포커스  ][ 2 ]
  [ 3 ][ 4 ][ 5 ]
  [ 6 ][ 7 ][ 8 ]
  ```

#### 🏛️ 10장 - Gallery
- **용도**: 종합 갤러리, 포트폴리오
- **구성**: 메인 이미지 + 다양한 크기의 갤러리
- **스타일**: 전시회, 작품집
- **셀 구조**:
  ```
  [  메인    ][ 1 ]
  [  이미지  ][ 2 ]
  [ 3 ][ 4 ][ 5 ]
  [ 6 ][ 7 ][ 8 ]
  [   하단 와이드   ]
  ```

## 🎨 디자인 가이드

### 시각적 계층 구조
1. **히어로 이미지**: 2x2 또는 더 큰 셀 사용
2. **보조 이미지**: 1x1 또는 1x2 셀 사용
3. **액센트 이미지**: 와이드(전체 너비) 또는 톨(전체 높이) 셀 사용

### 레이아웃 원칙
- **균형**: 큰 이미지와 작은 이미지의 적절한 분배
- **흐름**: 시선이 자연스럽게 이동하도록 배치
- **여백**: 프레임 간격을 통해 호흡감 부여
- **대비**: 크기 대비를 통한 시각적 흥미 유발

## 💡 향후 개선 방향

### Phase 2: 커스텀 레이아웃 빌더
- **드래그 앤 드롭**: 사진을 자유롭게 이동하여 재배치
- **크기 조절**: 각 셀의 크기를 동적으로 조정
- **레이아웃 저장**: 사용자 정의 레이아웃을 템플릿으로 저장

### Phase 3: 텍스트 오버레이 강화
- **헤드라인**: 큰 타이틀 텍스트 추가
- **캡션**: 각 사진에 설명 텍스트
- **본문**: 긴 텍스트 블록 지원
- **텍스트 스타일**: 다양한 폰트, 크기, 색상, 정렬

### Phase 4: 고급 기능
- **레이어 시스템**: 텍스트와 이미지의 레이어 관리
- **템플릿 마켓플레이스**: 커뮤니티 템플릿 공유
- **AI 레이아웃 제안**: 사진 분석 기반 자동 레이아웃 추천
- **애니메이션**: 레이아웃 전환 효과

## 📊 성공 지표
- 매거진 스타일 레이아웃 사용률 30% 이상
- 레이아웃당 평균 편집 시간 감소
- 사용자 만족도 조사 점수 향상
- 소셜 미디어 공유율 증가

## 💬 사용자 시나리오

### 시나리오 1: 여행 블로거
> "발리 여행 사진 10장으로 포토 에세이를 만들고 싶어요"
1. 10장 사진 선택
2. "Gallery" 레이아웃 선택
3. 메인 이미지(석양 사진)를 히어로 위치에 배치
4. 나머지 사진들이 자동으로 균형있게 배치
5. 텍스트 추가: "Bali Memories 2026"
6. 저장 및 Instagram 공유

### 시나리오 2: 이벤트 사진
> "친구 생일파티 사진 8장을 역동적으로 구성하고 싶어요"
1. 8장 이벤트 사진 선택
2. "Event Mosaic" 레이아웃 선택
3. 케이크 사진을 상단 와이드에 자동 배치
4. 나머지 파티 순간들이 모자이크로 배치
5. 프레임 간격 조절로 활기찬 느낌 연출
6. 저장하여 친구들과 공유

### 시나리오 3: 포트폴리오
> "내 작품 6장으로 전문적인 포트폴리오를 만들고 싶어요"
1. 대표 작품 6장 선택
2. "Modular Grid" 레이아웃 선택
3. 가장 강한 작품을 큰 모듈에 배치
4. 나머지 작품들이 모듈러 그리드로 정돈
5. 코너 라운딩과 간격으로 세련된 느낌
6. 포트폴리오로 저장

## 🔧 기술 구현 노트

### 그리드 시스템
- 4행 기준 그리드 시스템 유지
- 각 셀은 rowSpan과 columnSpan으로 크기 정의
- 4:5 비율의 캔버스에 최적화

### 레이아웃 타입
- 새로운 `LayoutType.magazine` 추가
- 기존 타입들과 함께 필터링 가능
- UI에서 "Magazine" 카테고리로 그룹화

### 성능 최적화
- 템플릿은 정적으로 정의하여 메모리 효율성
- 사진 로딩은 기존 캐싱 시스템 활용
- 레이아웃 전환 시 부드러운 애니메이션
